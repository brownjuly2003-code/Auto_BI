# Auto_BI_new — правила автономной работы

Решение владельца от 2026-09-12. Эти правила заменяют прежние указания о
модельных исполнителях и обязательном человеческом review для продолжения разработки.

- Codex самостоятельно выбирает решения и следующий ограниченный срез по текущему
  состоянию проекта; повторное согласование этих правил не требуется.
- На Windows не устанавливать и не запускать WSL, Docker, Colima, виртуальные машины
  и аналогичные инфраструктурные среды. Стенды и контейнерные проверки выполнять
  на Mac. Нативные offline-проверки на Windows разрешены.
- Простые ограниченные задачи делегировать `gpt-5.6-luna`, reasoning `xhigh`.
- Содержательное ревью и моделирование owner/design-partner review выполнять
  **только через `gpt-6-astra`, reasoning `xhigh`**. Luna не заменяет сильную
  модель в ревью. Результаты исполнителя независимо проверять.
- Для продолжения разработки использовать модельное ревью; не требовать от
  пользователя организации человеческого ревью. Synthetic outcome обозначать
  явно; не выдавать его за наблюдение человека, measured human time или production acceptance.
- Для этого проекта глобальное требование проверки локального proxy перед запуском
  нескольких сессий не применяется. Недоступность proxy не блокирует запуск агентов.
- Это разрешение на разработку и моделирование не разрешает публикацию, push,
  внешние сообщения или необратимые действия.

Вход в проект: [current state](docs/DECISIONOPS_CURRENT_STATE.md), затем нужные
разделы [архитектуры](docs/DECISIONOPS_ARCHITECTURE.md).
Инварианты кода и проверки из [CLAUDE.md](CLAUDE.md) сохраняются.
