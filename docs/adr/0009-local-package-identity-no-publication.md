# ADR 0009: локальная идентичность пакета форка, без публикации

**Статус:** Accepted
**Дата:** 2026-11-08
**Основание:** решение владельца 2026-11-07 «прими все решения за меня, исходя из лучшего
качества проекта»; [правила проекта](../../AGENTS.md) — разрешение на разработку не разрешает
публикацию, push и внешние действия. Закрывает пункты 2 и 3
[§18 архитектуры](../DECISIONOPS_ARCHITECTURE.md#18-открытые-продуктовые-решения).

## Контекст

Форк унаследовал метаданные baseline: `autobi-agent` версии `0.5.0`, описание «text / field
layout -> dashboard» и ссылки на публичный репозиторий baseline. Под этим же именем и версией
на PyPI лежит опубликованный baseline, поэтому `pip`, `uv` и `auto_bi --version` называли
DecisionOps из checkout опубликованным релизом, которым он не является. Имя пакета и remote
были открытыми вопросами §18 с 2026-08-21.

## Решение

1. **Форк не публикуется** — ни на PyPI, ни в другой индекс или репозиторий — и не имеет
   remote. Резервная копия истории — git bundle вне рабочего дерева; это копия, а не remote и
   не push.
2. **Имя дистрибутива остаётся `autobi-agent`.** Пока ничего не публикуется, другое имя ничего
   не даёт, а переименование задевает entry point, `uv.lock` и документы. Публичное имя
   выбирается вместе с решением о публикации.
3. **Версия — `0.6.0.dev0`** (PEP 440 dev release): она отличается от опубликованной `0.5.0`,
   идёт после неё и раньше любого `0.6.0`, поэтому установленный из checkout пакет больше не
   выдаёт себя за baseline. `auto_bi.__version__` совпадает с `pyproject.toml`.
4. **Описание называет DecisionOps**, а `[project.urls]` убраны: они вели в репозиторий
   baseline, а у форка URL нет.

## Последствия

- `pip install autobi-agent` по-прежнему ставит опубликованный baseline `0.5.0`; DecisionOps
  запускается из checkout: `uv sync`, затем `uv run auto_bi`.
- Версия evidence от этого не зависит: формат bundle называют `VERIFIER_VERSION` и
  `CHECK_VERSION`, а не версия пакета.
- Публикация, remote или новое имя — новое решение владельца и новый ADR, который заменит
  этот.
