# ADR 0006: продолжение разработки через моделирование на Astra xhigh

**Статус:** Accepted
**Дата:** 2026-09-12
**Основание:** прямое решение владельца; [правила проекта](../../AGENTS.md).

## Решение

Для выбора и ревью следующих срезов разработки требуется только моделирование
через `gpt-6-astra` с reasoning `xhigh`. Организация человеческого owner/design-partner
review больше не является условием продолжения разработки. Это заменяет procedural
human gate из пунктов 2 и 5 [ADR 0004](0004-synthetic-proxy-offline-investigation.md).

Сильная модель исследует актуальные отчёты и контракты, моделирует решение владельца,
фиксирует findings с evidence и предлагает один ограниченный implementation-срез.
Простые задачи исполняет Luna xhigh; Codex независимо проверяет изменения и тесты.
Модельное ревью не выполнено, пока нет фактического результата Astra xhigh.

Сохраняются технические gates, запрет необоснованных factual/causal claims и
границы внешних действий. Новый порядок не означает автоматического запуска
scheduler, REST/MCP, notifications или actions: сначала конкретный срез и его review.
Результаты моделирования не являются human acceptance, измерением времени человека
или production certification. Ранее сохранённые evidence и обзоры не переписываются.

## Исполнение и текущий блокер

WSL, Docker и аналогичные среды на Windows запрещены; стенды выполнять на Mac.
При проверке 2026-09-12 соединение с proxy `127.0.0.1:12334` завершилось ошибкой.
По глобальному правилу Session Concurrency модельные агенты не запускались.
Следующий шаг — после восстановления proxy выполнить Astra xhigh review signed R3
пакета и findings R3/R4; его результат определит следующий срез. Повторять проверку
без изменения состояния proxy или нового входа не требуется.
